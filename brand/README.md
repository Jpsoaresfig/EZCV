# Marca Fíchame

Ficheiros para usar fora do sistema (redes sociais, cartões, cartazes, apresentações).

| Ficheiro | Uso |
|---|---|
| `fichame-simbolo.svg` | Símbolo em vetor — escala sem perder qualidade. Preferir este para impressão |
| `fichame-simbolo-512.png` / `-1024.png` | Símbolo em PNG — foto de perfil (Instagram, WhatsApp, Google) |
| `fichame-logo-claro.png` | Símbolo + nome, fundo transparente, para fundos claros |
| `fichame-logo-escuro.png` | Símbolo + nome, fundo transparente, para fundos escuros |

**Símbolo «Ficha»:** uma ficha de candidato (foto + dados) a chegar por NFC.

**Cores**

| | Hex |
|---|---|
| Terracota (principal) | `#c9402a` |
| Gradiente do símbolo | `#d9553d` → `#8e2b1c` |
| Texto | `#1c1917` |
| Fundo claro | `#f6f4f2` |
| Fundo escuro | `#16140f` |

**Tipografia do nome:** sans-serif do sistema em peso 800 (Segoe UI no Windows, San Francisco no Mac/iPhone), com espaçamento entre letras ligeiramente apertado.

A fonte original do símbolo é `public/img/logo.svg`; os favicons (`public/favicon.*`, `public/apple-touch-icon.png`) são gerados a partir dele.
